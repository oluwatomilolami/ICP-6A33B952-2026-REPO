# Week 1: Project Selection

## Introduction

As part of the InternCareerPath Full Stack Web Development Internship, I reviewed the available projects in the Project Bank and selected two projects that align with my current skills while also providing opportunities to strengthen my practical web development abilities.

The selected projects are:

1. Personal Portfolio Website
2. E-Commerce Product Catalog

---

## Project 1: Personal Portfolio Website

### Reason for Selection

I selected the Personal Portfolio Website because a professional online portfolio provides an effective way to present my skills, experience, projects, certifications, education, and professional background.

The project will also allow me to strengthen my understanding of responsive web design, user interface development, accessibility, and deployment while creating a practical platform that can be used beyond the internship.

### Technologies

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* Responsive Web Design

### Planned Features

* About section
* Skills section
* Projects section
* Professional experience section
* Certifications section
* Education section
* Contact section
* Responsive navigation
* Responsive design across different screen sizes
* Downloadable CV
* Project links
* Contact form
* Basic accessibility and SEO practices

### Expected Outcome

A responsive, professional, and user-friendly portfolio website that effectively presents my technical skills, projects, certifications, education, and professional experience.

## Project 2: E-Commerce Product Catalog

### Reason for Selection

I selected the E-Commerce Product Catalog to develop stronger practical experience with React and modern frontend application development.

The project will provide an opportunity to work with routing, APIs, reusable components, application state, product filtering, search functionality, and shopping cart management.

### Technologies

* React.js
* JavaScript
* React Router
* REST API
* HTML5
* CSS3
* Git and GitHub
* LocalStorage

### Planned Features

* Product listing
* Product search
* Category filtering
* Product detail pages
* Shopping cart
* Add and remove products from cart
* Product quantity management
* Persistent cart data
* Loading states
* Error handling
* Responsive design

### Expected Outcome

A responsive and functional e-commerce product catalog that demonstrates practical frontend development skills, API integration, state management, routing, and responsive UI development.
