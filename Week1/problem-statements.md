# Week 1: Problem Statements

## Project 1: Personal Portfolio Website

### Problem Statement

Professionals and developers need an accessible and well-organized online presence where they can present their skills, experience, education, certifications, and projects to potential employers, clients, and professional connections.

Traditional CVs provide limited space to demonstrate practical work and often do not provide an interactive way to explore a person's projects or technical abilities. Without a centralized professional portfolio, it can also be difficult for recruiters and potential clients to quickly understand an individual's capabilities and experience.

### Proposed Solution

I will develop a responsive personal portfolio website that serves as a centralized professional platform for presenting my background, technical skills, projects, education, certifications, and experience.

The website will provide clear navigation and responsive layouts so that visitors can easily access relevant information across different devices.

### Target Users

* Recruiters and hiring managers
* Potential clients
* Professional connections
* Other developers and technology professionals

### Success Criteria

The project will be considered successful if:

* The website is fully responsive across desktop, tablet, and mobile devices.
* Users can easily navigate between sections.
* Projects can be viewed with relevant descriptions and links.
* Skills, certifications, education, and experience are clearly presented.
* The website includes a functional contact method.
* The website is deployed and publicly accessible.
* The code is organized and documented using GitHub.

## Project 2: E-Commerce Product Catalog

### Problem Statement

Customers often need a simple and efficient way to discover products, compare available options, view detailed product information, and manage items they are interested in purchasing.

A poorly organized product interface can make it difficult for users to find relevant products, understand product information, or manage their selections. Businesses therefore benefit from digital product catalogs that organize products and provide useful browsing and shopping features.

### Proposed Solution

I will develop a responsive e-commerce product catalog that allows users to browse products, search for specific items, filter products by category, view individual product details, and manage selected products through a shopping cart.

The application will consume data from a REST API and use client-side state management and local storage to provide a smooth and persistent user experience.

### Target Users

* Online shoppers
* Customers browsing products
* Small businesses seeking a digital product showcase
* Users interested in comparing and managing products before purchase

### Success Criteria

The project will be considered successful if:

* Products are retrieved and displayed correctly from a REST API.
* Users can search for products.
* Users can filter products by category.
* Users can view individual product details.
* Users can add and remove products from the shopping cart.
* Users can adjust product quantities.
* Cart information persists between browser sessions.
* The application handles loading and error states appropriately.
* The interface is responsive across different screen sizes.
* The application is deployed and publicly accessible.
* The code is organized and documented using GitHub.

---

## Summary

The two projects address different but complementary objectives.

The **Personal Portfolio Website** focuses on professional presentation, responsive design, and web development fundamentals, while the **E-Commerce Product Catalog** focuses on building a more interactive application using React, API integration, routing, and state management.

Together, the projects will provide practical experience across different stages of the web development process, from planning and interface development to application functionality, testing, deployment, and documentation.
